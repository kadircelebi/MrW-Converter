## Notes for certification (1986 karakter)

```text
MrW Converter is a desktop file converter (WPF, MSIX). It converts, shrinks and edits pictures, sound, video and PDFs on the user's computer. No account, sign-in, purchase or test credentials are needed.

How to test:
1. Start the app and drop a picture or video on the window, or use Choose files. Pick a format and press Convert. The result appears beside the original.
2. Under Tools, try Shrink and Remove background.
3. Drag wheel: it is off by default. Turn on the Drag wheel setting at the bottom of the window. Drag a file from File Explorer, press Shift during the drag, and let go on a slice. Pausing over Tools shows the tools. For files in the list, Ctrl+Space opens the same wheel with no drag.
4. Optional: turn a Word document into PDF. The app first asks whether to download LibreOffice (see below).

How the wheel works: while the setting is on, the app uses SetWinEventHook to learn that the system's drag image window has appeared, and reads Ctrl, Shift and Alt only during that drag. It has no keyboard or mouse hooks and sends no input.

Network: the app goes online for one thing. Converting Office files to PDF needs LibreOffice, a free office suite not in the package. On first use the app asks; if the user agrees it downloads a pinned, checksum-verified copy from documentfoundation.org (376 MB) into its own data folder, removed on uninstall. The start of the description says so. Documents are never sent anywhere. No telemetry. Background removal uses an on-device model in the package.

Startup: an optional startup task, off until the user turns it on. Closing the window asks before hiding to the tray.

Support: the About window has a voluntary Buy Me a Coffee link. It unlocks nothing.

runFullTrust: Win32/WPF desktop app. It reads and writes the files the user chooses, runs the bundled FFmpeg as a child process, and shows the wheel over other windows. No services, drivers or admin rights.

Privacy policy: https://converter.mrwproject.com/privacy/
```
